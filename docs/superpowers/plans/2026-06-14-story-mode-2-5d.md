# Story Mode 2.5D Visuals Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert story mode into a C2 balanced cinematic 2.5D view while preserving the current 2D gameplay coordinates, combat rules, enemy AI, and non-story modes.

**Architecture:** Add a focused story 2.5D projection module under `src/visual`, then route story-mode visual placement through it. Keep gameplay state in logical world coordinates and project only rendering, camera, pointer inverse mapping, actor anchors, story art sprites, and debug metrics.

**Tech Stack:** TypeScript, PixiJS v8 `Container`/`Graphics`/`Sprite`/`AnimatedSprite`, Vitest/jsdom, Playwright, Vite.

---

## Scope Boundary

This plan implements the approved spec in `docs/superpowers/specs/2026-06-14-story-mode-2-5d-design.md`.

In scope:

- Story mode only.
- C2 balanced cinematic view.
- Visual projection first: logical world coordinates stay unchanged.
- Foot-anchored vanguard and zombie story sprites.
- Projected story slice map/lighthouse/fog.
- Story-mode camera, pointer, weapon, projectile, and effect visual alignment.
- Stable y-depth ordering for story actors and key props.
- Debug metrics and e2e assertions that prove the 2.5D path is active.

Out of scope:

- Classic mode visual changes.
- Boss Rush visual changes.
- Full isometric coordinate system.
- Rebuilding collision, pathfinding, enemy AI, or damage math.
- Large new asset generation.
- New cutscenes.

## File Structure

- `src/visual/story2_5dProjection.ts`: C2 projection config, world-to-screen mapping, inverse mapping, projected angle, and depth helpers.
- `src/visual/story2_5dProjection.test.ts`: unit tests for projection, inverse mapping, and depth ordering.
- `src/visual/storyActorVisuals.ts`: story actor scale and foot-anchor constants, applied to `AnimatedSprite` anchors.

- `src/game/PixiWastelandGame.ts`: story-mode projection integration for camera, pointer, actor positions, story slice renderer, weapon visuals, projectiles, effects, and metrics.

- [ ] **Step 3: Implement the projection module**

Create `src/visual/story2_5dProjection.ts`:

```ts
export interface StoryPoint {
  x: number;
  y: number;
}

export const STORY_2_5D_CONFIG = {
  groundScaleY: 0.56,
  actorScaleBoost: 1.1,
  weaponYOffset: -18,
  effectYOffset: -8,
  depthStride: 10,
} as const;

export function projectStoryPoint(point: StoryPoint, origin: StoryPoint): StoryPoint {
  return {
    x: point.x,
    y: origin.y + (point.y - origin.y) * STORY_2_5D_CONFIG.groundScaleY,
  };
}

export function unprojectStoryPoint(point: StoryPoint, origin: StoryPoint): StoryPoint {
  return {
    x: point.x,
    y: origin.y + (point.y - origin.y) / STORY_2_5D_CONFIG.groundScaleY,
  };
}

export function projectStoryAngle(from: StoryPoint, to: StoryPoint, origin: StoryPoint): number {
  const projectedFrom = projectStoryPoint(from, origin);
  const projectedTo = projectStoryPoint(to, origin);

  return Math.atan2(projectedTo.y - projectedFrom.y, projectedTo.x - projectedFrom.x);
}

export function getStoryDepth(point: StoryPoint, offset = 0): number {
  return point.y * STORY_2_5D_CONFIG.depthStride + offset;
}
```

```ts
  private getStoryProjectionOrigin(): StoryPoint {
    return STORY_CENTER_LIGHTHOUSE.position;
  }

  private projectPoint(point: StoryPoint): StoryPoint {
    if (!this.isStoryMode()) return point;
    return projectStoryPoint(point, this.getStoryProjectionOrigin());
  }

  private unprojectPoint(point: StoryPoint): StoryPoint {
    if (!this.isStoryMode()) return point;
    return unprojectStoryPoint(point, this.getStoryProjectionOrigin());
  }

  private setViewPosition(view: Container, x: number, y: number, visualYOffset = 0): void {
    const projected = this.projectPoint({ x, y });
    view.position.set(projected.x, projected.y + (this.isStoryMode() ? visualYOffset : 0));
  }

  private getStoryVisualDepth(point: StoryPoint, offset = 0): number {
    return this.isStoryMode() ? getStoryDepth(point, offset) : 0;
  }
```
