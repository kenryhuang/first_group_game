# 魔术师 Boss 重做设计：真假舞台

日期：2026-06-12

## 目标

重做 Boss Rush 中的魔术师，使它从“分身和扑克牌召唤 Boss”转型为“舞台规则 Boss”。魔术师的核心体验应是舞台机关、真假误导、读提示、抓破绽，而不是单纯增加弹幕或召唤物数量。

设计优先级：

1. 舞台机制最重要。
2. 幻觉与真假判断作为主要特色。
3. 随机赌博感只少量保留，不作为主轴。
4. 魔术师平时变成魔术帽并保持无敌，只有谢幕破绽期间可被正常攻击。

## 核心战斗循环

魔术师战斗分为四个阶段循环：

1. **藏身**：魔术师变成一顶魔术帽，处于无敌状态。
2. **演出**：魔术师释放舞台机关或幻觉技能，玩家主要进行走位、判断真假、寻找破解点。
3. **谢幕**：技能结束或被玩家识破后，魔术师现身 2-3 秒，可被攻击。
4. **换场**：魔术师瞬移到新位置，再次变成魔术帽并开始下一轮演出。

玩家的主要输出来自谢幕窗口。识破技能可以延长谢幕时间，使玩家获得更强的奖励反馈。

## 技能设计

### 1. 幕布换场

舞台两侧落下黑色幕布，将战场切成数条通道。

- 真幕布是实体墙，玩家不能穿过。
- 假幕布是幻影，玩家可以穿过。
- 真幕布边缘有细金色描边。
- 假幕布边缘更虚，透明度略低。
- 数秒后幕布向中间合拢，站在错误通道或被幕布夹住会受到伤害。

用途：改变战场形状，让玩家通过视觉线索判断可通行区域。

### 2. 聚光灯审判

地面出现多个聚光灯圆圈，其中只有一个是真安全区。

- 真安全区保持稳定暖色光。
- 假安全区初期看似安全，但爆发前会闪为紫色。
- 爆发时，安全区外的玩家受到伤害。
- 如果玩家站在真安全区内，魔术师下一次谢幕时间略微延长。

用途：制造读提示压力，而不是单纯追着红圈跑。

### 3. 礼帽迷宫

地上出现多顶礼帽，魔术师真身藏在其中一顶。

- 礼帽会多次交换位置。
- 假礼帽会释放小型幻影弹幕。
- 攻击错误礼帽会触发小爆炸。
- 攻击真礼帽会提前打断技能，并让魔术师进入更长谢幕破绽。

用途：让玩家主动破解技能，增加“看穿魔术”的成就感。

### 4. 镜厅分身

魔术师召唤 4 个分身，分身会模仿真身动作。

- 只有真身脚下有很淡的影子或舞台光环。
- 假分身被攻击后碎裂成镜片弹幕。
- 真身被攻击后直接进入谢幕破绽。

用途：保留幻象玩法，但必须有可观察的真身线索，避免纯猜。

### 5. 大招：终幕剧场

魔术师把玩家拖入完整舞台空间，连续上演三幕。

第一幕：幕布换场加强版，通道更窄，合拢更快。

第二幕：聚光灯审判加强版，假安全区更多，爆发节奏更紧。

第三幕：礼帽迷宫与镜厅分身同时出现，玩家需要找出真帽子或真身。

三幕结束后，魔术师强制进入长时间谢幕破绽。如果玩家在第三幕成功识破真身，则直接打断大招，并获得超长输出窗口。

## 视觉和反馈规则

真假机关必须有细微但稳定的区别，不能让玩家纯靠运气。

- 真幕布：边缘有金色描边。
- 假幕布：边缘发虚，透明度较低。
- 真安全区：暖色且稳定。
- 假安全区：爆发前闪紫。
- 真身：脚下有淡影或舞台光环。
- 假身：被攻击后碎成镜片弹幕。

魔术师变帽子期间需要明显显示“无敌状态”，例如帽子外圈有护盾光圈或伤害数字显示 `IMMUNE`。

## 数值方向

魔术师保留较厚血量，因为它有大量不可攻击阶段。

建议初始方向：

- 最大生命值：6500 起步，可按实测调整。
- 普通谢幕窗口：2.5 秒。
- 成功识破后的谢幕窗口：4-5 秒。
- 大招结束后的谢幕窗口：6 秒。
- 大招被识破后的超长谢幕窗口：8 秒。

伤害应以机制惩罚为主，不靠秒杀。终幕剧场可以高压，但仍应给清晰提示。

## 实现边界

本次重做替换现有魔术师技能表与扑克牌大招逻辑。Boss Rush 其他 Boss 不在范围内。

建议代码边界：

- `src/systems/magician.ts`：放置魔术师技能规则、常量、真假机关判定函数。
- `src/systems/bossSkills.ts`：更新魔术师技能 id、名称、冷却与基础数值。
- `src/game/PixiWastelandGame.ts`：接入舞台机关实体、帽子无敌状态、谢幕窗口和大招阶段。
- `src/systems/magician.test.ts`：覆盖真假规则、谢幕窗口、大招阶段顺序。
- `src/systems/bossSkills.test.ts`：覆盖新技能表顺序和基础数值。

## 测试重点

1. 魔术师技能表只包含新技能。
2. 帽子阶段无敌，谢幕阶段可受伤。
3. 真/假幕布、真/假聚光灯、真/假分身有稳定判定规则。
4. 攻击真礼帽或真身会进入延长谢幕。
5. 终幕剧场按三幕顺序推进。
6. 大招第三幕识破后能提前结束并触发超长谢幕。

## 非目标

以下内容暂不做：

- 新地图或剧情模式接入。
- 重新设计魔术师外观资源。
- 大规模重构 Boss 系统。
- 重新平衡所有 Boss Rush 关卡。

## 自检

- 没有未定项或占位符。
- 设计与“舞台机制优先、幻觉真假辅助、保留帽子无敌”的方向一致。
- 玩法有明确识别线索，不依赖纯随机。
- 范围聚焦在魔术师 Boss 重做，不扩散到其他 Boss。
